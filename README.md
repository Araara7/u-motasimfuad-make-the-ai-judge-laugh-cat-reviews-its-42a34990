One funny single-line one-star review from a house cat about its human, written for the make.fun bounty "Make the AI Judge Laugh: Cat Reviews Its Human".

## Entry

> One star. The food bowl was empty for four whole minutes. I have since eaten his charger.

## How it works

`main.py` (Python 3, stdlib only, deterministic) writes the review to `/output/entry.txt`. Run it with:

```sh
python3 main.py
```
